# German

## Every text

| Rule | Write | Not |
|---|---|---|
| Name who acts | Wir haben den Wert um 14:40 zurückgesetzt. | Der Wert wurde um 14:40 zurückgesetzt. |
| `ist` where it fits, since `dient als` and `fungiert als` only sound grander | Das Modul ist die Schnittstelle zum Bezahldienst. | Das Modul dient als Schnittstelle zum Bezahldienst. |

## Procedures and instructions

| Rule | Write | Not |
|---|---|---|
| Condition before action | Wenn die Platte voll ist, stoppe den Import. | Stoppe den Import, wenn die Platte voll ist. |
| `darf nicht` for what is forbidden | `pg_restore` darf nicht abgebrochen werden. | `pg_restore` muss nicht abgebrochen werden. |

`muss nicht` means that a step is not needed, so using it for a prohibition reverses the
instruction. When notes use it that way, correct it.
