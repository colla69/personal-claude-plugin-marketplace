# English

## Every text

| Rule | Write | Not |
|---|---|---|
| Name who acts | The deploy job dropped the table. | The table was dropped. |
| Three nouns in a chain at most, since a longer chain hides which word modifies which | the retry timeout for the session cache | the session cache retry timeout |

## Procedures and instructions

| Rule | Write | Not |
|---|---|---|
| Condition before action | If the disk is full, stop the import. | Stop the import if the disk is full. |
| A step is a command. "Must" states a requirement, since "should" reads as optional | Back up the database first. The backup must finish before you continue. | You should back up the database first. |
| No contractions, since the negation inside one is the word that gets missed | Do not restart the service. | Don't restart the service. |

Reports and explanations keep their contractions and their ordinary "should". There they
sound natural and cost nothing.
