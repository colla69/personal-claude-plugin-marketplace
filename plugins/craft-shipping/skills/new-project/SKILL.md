# New project

In an empty folder there is nothing to detect. Any stack you pick comes from the
user's sentence and your own habits, and a scaffold in the wrong stack is thrown away.

## Ask before the first file

Name the stack you would pick and why, name one real alternative, and ask which one
before you create any file. Never present a guess as if you detected it. Skip the
question only when the user already named the stack.

## Where this yields

- **To the user's answer**, and to a stack they already named.
- **To an existing project.** A folder with code in it has conventions to follow.
