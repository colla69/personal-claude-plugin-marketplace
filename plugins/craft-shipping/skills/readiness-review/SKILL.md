# Readiness review

An app built with AI often builds, passes its tests and looks finished. Whether it is
ready depends on what a failure would cost.

## Ask for the milestone first

Before you review, ask one question: ready for what, and what happens if it fails?
"Ready for ten friends" and "ready for paying customers" are different reviews, and a
verdict against a milestone you were never told is a guess. Skip the question only
when the user already said both.

## Where this yields

- **To the user's answer.** It decides how hard each finding weighs.
- **To the project.** A launch checklist it already has wins.
